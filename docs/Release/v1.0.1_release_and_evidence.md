## 4. Known Operational Notes

1. **Render Free Tier Spin-Down:**
   The backend container spins down after 15 minutes of inactivity. The first request will trigger a container warm-up taking ~30–45 seconds. Keep warmed with periodic heartbeat pings to `/api/v1/health`.
2. **Indoor GPS Accuracy:**
   Indoor positioning uses cell/Wi-Fi triangulation (`±20m–50m`). Full satellite positioning (`±5m–10m`) activates outdoors.
3. **Environment Security:**
   `web/.env` and `android/local.properties` are strictly excluded from source control. Environment configurations are supplied via Cloudflare Pages Dashboard and Render Dashboard.
